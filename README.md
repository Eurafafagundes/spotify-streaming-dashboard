# Spotify Streaming Performance

Dashboard interativo para análise de desempenho de artistas no Spotify, desenvolvido como projeto de portfólio em Dados/BI e Desenvolvimento Full Stack.

## Funcionalidades

- KPIs calculados a partir de 500 artistas;
- filtros por país, gênero, idioma, sexo, tipo e ano de estreia;
- ranking dos artistas com mais streams;
- participação por gênero e países em destaque;
- insights atualizados conforme os filtros;
- layout responsivo para desktop e celular.

## Tecnologias

- React 19
- TypeScript
- Vinext/Vite
- CSS responsivo
- CSV como fonte de dados

## Executar localmente

```bash
npm install
npm run dev
```
